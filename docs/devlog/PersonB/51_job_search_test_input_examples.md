# 51. 취업 정보 검색 다음 테스트 라운드용 입력 예시 목록

devlog 44~50에 걸친 실계정 테스트(총 27개 이상의 질의, 5개 수정 라운드)에서
쓴 직업/시나리오는 이미 상당수 소진됐다. 이 파일은 **다음 번 취업 정보 검색
실계정 테스트를 더 빠르게 시작하기 위한 참고 자료**다 — 새로운 직업 예시와,
이번 세션에서 발견한 버그 유형별 회귀 확인용 질의를 미리 뽑아둔다.

**사용법**: `window.fetch`를 가로채는 방식(이번 세션 내내 쓴 방법 — 홈에서
`window.fetch`를 감싸 `job-search/query` 요청/응답을 `window.__jobSearchLog`에
기록)으로 실제 요청·응답을 캡처하며 진행할 것. 카테고리 선택, `broadened`
플래그, `unsupported_note` 값은 화면 텍스트만으로는 안 보이므로 반드시 이
방식을 쓴다. 이 목록의 직업이 다음 라운드에서 다 쓰이면, 이 파일에 새 직업을
추가하거나 새 파일로 이어간다.
