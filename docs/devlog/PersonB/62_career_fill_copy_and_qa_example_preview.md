# 62. 커리어 채우기 문구 명확화 + 문답 예시 미리보기 (2026-09-17)

챔피언십 쇼케이스 마무리 작업. 랜딩 페이지 문구가 "공백기만 다룬다"는
인상을 줄 수 있었고, 클릭 전에는 대화가 실제로 어떻게 흘러가는지 전혀
보이지 않았다는 점을 보완.

## 무엇을

- 커리어 채우기 카드 문구를 재직/공백 기간 모두를 다루고, 떠오르는 경력이
  없어도 AI가 후속 질문으로 구체화한다는 점을 명시하도록 수정
  (`frontend/app/page.tsx`)
- 취업 정보 검색 카드 문구에 커리어 채우기 기능과의 연계를 명시
- "문답 예시 보기" 버튼 + `ExampleInterviewModal.tsx` 신규 — 기존
  `ExampleDocumentModal`(결과물 예시)과 같은 모달 뼈대를 재사용하되, 본문은
  `InterviewChatThread`가 실제 대화에 쓰는 `ChatBubble`로 채워 "딱히
  떠오르는 경력이 없어요"에 AI가 후속 질문으로 파고드는 흐름 자체를 클릭
  전에 미리 보여줌

## 검증

- 로컬에서 랜딩 페이지 렌더링 확인 (별도 백엔드 API 호출 없는 순수 프론트
  변경)
